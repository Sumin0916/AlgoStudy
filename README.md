# AlgoStudy

알고리즘 문제 풀이와 문제 출제/세팅 자료를 정리한 개인 알고리즘 아카이브입니다.

이 저장소는 백준 문제 풀이를 알고리즘 유형별로 정리한 풀이 모음집이며,  
단순 풀이 코드뿐 아니라 대회/스터디 풀이, 문제 출제 과정에서 필요한 generator, validator, checker 등의 문제 세팅 자료도 함께 포함하고 있습니다.

## Overview

- 기간: 2023.07 ~ 2024.11
- 규모: 250개 이상의 풀이 파일
- 언어: C++, Python 중심
- 구성:
  - 알고리즘 유형별 풀이 정리
  - 스터디 주차별 풀이
  - 대회별 문제 풀이 모음
  - 문제 출제 및 테스트 데이터 세팅 자료
